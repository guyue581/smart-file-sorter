# 智能文件分拣工具使用说明

## 📁 软件介绍

智能文件分拣工具是一款高效、智能的文件管理工具，能够帮助您快速整理和分类大量文件。

### 主要功能
- ✅ 根据关键词自动分拣文件
- ✅ 支持文件类型过滤
- ✅ 自定义文件夹结构
- ✅ 预览匹配文件
- ✅ 详细的分拣日志
- ✅ 配置保存和加载
- ✅ 多种皮肤主题

### 适用场景
- 整理下载文件夹中的各种文件
- 分类工作文档和资料
- 管理照片和视频文件
- 批量处理文件整理任务

## 🚀 安装方法

### 方法一：直接运行可执行文件（推荐）
1. 找到`智能文件分拣工具.exe` 文件
2. 双击即可运行，无需安装 Python 环境
3. 可以将该文件复制到任何位置使用

### 方法二：从源码运行
1. 确保已安装 Python 3.7 或更高版本
2. 安装依赖包：
   ```bash
   pip install ttkbootstrap
   ```
3. 运行 `智能文件分拣工具.py` 文件

## 📖 基本使用步骤

### 1. 设置路径
- **源文件夹**：点击按钮选择要分拣的文件夹
- **目标文件夹**：点击按钮选择文件保存位置

### 2. 配置分拣规则
- **包含关键词**：输入要匹配的关键词（多个关键词用空格分隔）
- **排除关键词**：输入要排除的关键词
- **文件夹创建**：选择是否新建文件夹以及文件夹创建方式
- **文件操作**：选择是复制还是移动文件

### 3. 设置文件类型
- **文件类型过滤**：勾选要处理的文件类型
- **文件格式设置**：点击按钮详细配置每种文件类型包含的具体格式
- **自定义扩展名**：添加不在列表中的文件扩展名

### 4. 预览和执行
- **预览**：点击按钮查看匹配的文件
- **开始分拣**：确认无误后点击按钮执行分拣操作
- **停止**：如有需要，点击按钮终止操作

### 5. 查看结果
- 分拣完成后可以在目标文件夹查看整理结果
- 点击**查看日志**按钮查看详细的分拣记录

## ⚙️ 高级功能

### 组合关键词匹配
1. 勾选"使用组合关键词匹配"选项
2. 在"组合关键词"输入框中输入属性词（如：身份证、学历等）
3. 系统会自动将包含关键词与属性词组合进行匹配
4. 示例：包含关键词输入"张三 李四"，组合关键词输入"身份证"，系统会匹配包含"张三身份证"或"李四身份证"的文件

### 配置管理
- **保存配置**：点击按钮将当前配置保存为JSON文件
- **加载配置**：点击按钮加载之前保存的配置
- **方便在不同场景下快速切换配置**

### 自定义文件夹名称
- 在"自定义文件夹名称"输入框中输入名称
- 分拣时会使用该名称创建主文件夹
- 留空则使用默认名称"匹配文件夹"

## 🎨 皮肤主题

软件提供多种皮肤主题，可根据个人喜好选择：

- **现代薄荷**：清新现代的薄荷绿色主题
- **蓝色渐变**：蓝色渐变风格，现代简洁
- **经典商务**：经典商务蓝色风格，类似IE浏览器的界面

### 切换皮肤方法
1. 点击**皮肤选择**按钮
2. 在弹出的对话框中选择喜欢的皮肤
3. 点击**应用**按钮，软件会重启并应用新皮肤

## ❓ 常见问题

### Q: 为什么有些文件没有被分拣？
**A:** 请检查以下几点：
- 文件是否符合选择的文件类型
- 文件名是否包含设置的关键词
- 文件名是否包含排除的关键词
- 文件路径是否有特殊字符或权限问题

### Q: 分拣速度很慢怎么办？
**A:** 可以尝试以下方法：
- 减少同时处理的文件类型
- 只勾选必要的文件格式
- 缩小源文件夹的范围
- 关闭其他占用系统资源的程序

### Q: 如何批量处理多个文件夹？
**A:** 可以使用配置管理功能：
- 为每个文件夹创建一个配置文件
- 依次加载配置并执行分拣

### Q: 分拣后文件丢失了怎么办？
**A:** 请检查：
- 目标文件夹路径是否正确
- 是否有足够的磁盘空间
- 查看分拣日志了解详细情况
- 如果使用移动操作，文件会从源文件夹移除

## ⚠️ 注意事项

1. **文件安全**：建议在分拣前备份重要文件，特别是使用移动操作时
2. **权限问题**：确保对源文件夹和目标文件夹有读写权限
3. **文件大小**：处理大量或大体积文件时可能需要较长时间
4. **路径长度**：Windows系统对文件路径长度有限制，过长的路径可能导致操作失败
5. **重复文件**：软件会自动处理重名文件，添加"_副本"后缀
